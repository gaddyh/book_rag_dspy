# Book RAG with DSPy

A book retrieval-augmented generation system using DSPy for optimization.

## Installation

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Project Structure

- `data/`: Raw and processed data
- `src/book_rag/`: Core package modules
- `evals/`: Evaluation datasets
- `reports/`: Evaluation reports
